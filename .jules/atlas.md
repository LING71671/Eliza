## 2026-07-11 - Fixing ElizaBot fallback tests
**Learning:** The 'should handle fallbacks' test previously failed because it only asserted the response belonged to the `fallbacks` list, ignoring that arbitrary strings can trigger the catch-all pattern `/(.*)/i`. Tests need to account for both standard fallbacks and responses generated by the catch-all rule (with properly interpolated `{0}` placeholders).
**Action:** Updated `ElizaBot.test.ts` to verify the response against the union of `fallbacks` and the `/(.*)/i` pattern's responses. Ensure future tests testing edge cases evaluate against all relevant generic catch-all rules in `elizaScript.ts`.
